性 命 法 诀 明 指

第 十 六 法 诀 · 虚 空 显 形

打破虚空消息路，我登彼岸不用舟。

炼神还虚千变化，撒手虚空是金身。

炼就这个不坏体，十方世界归化身。

撒手逍遥是这个，这个虚实是不空。

　　身外有身末为奇特，虚空粉碎方露全真。撒手虚空回归空空，聚者显形空而不空。

　　还虚面壁之功，古云总得九年。我功末至此，我师传授口诀，今传于后。我师了空禅师曰： " 还虚一着，是将从前十魔百炼，不动心。通天达地之阳神，分形散影，显化于世，救急消灾，与人治病。复将阳神收入祖窍，归于性海之内，勿另其出色身。复将色身闭住炼化，浑入法身之中，此是先天之中先天性命。复将阳神退藏法身祖窍之内，要将色身炼得不有不无，非色非空，无内无外，不出不入，无始无终。如龙养珠，蛰藏而不动。如鸡抱卵，安眠而不起，沉之又沉 ; 静之又静，从前所修所证，百千万亿化身，乘龙跨钨，步口玩月，千变万化，一齐收入祖窍之内，依灭尽定，而寂灭之。此是矗龙之法，必须大死一场。谨谨护持，毋容阳神可由。益阳神百炼而百灵，千炼而愈精。炼炼不已，则阳神之总光内神火隐而收之愈密，斯放之愈普。隐之无可隐，斯显之无可显。将阳神收藏祖窍之内，定极灭尽之余，久而久之，将阳神真火养足，而一炉神光，凡几腾腾。满鼎真火，炎炎烈烈。自内窍透出外窍，由大窍贯大小窍。毛内无外，无大无小，透顶彻底，光光相烛，窍窍相映。而天地万物 : 莫不照耀于神光之中矣。炼至三年、九载、百年、千年、千劫、万动，直待四大崩散，虚空粉碎，无形无迹。此乃是带肉大觉金仙，万劫不坏金刚之体。 . 法诀至此，永无秘诀也。 " 

　　顺一子问日 :" 师传后将色身闭住炼化，性命复旧法鼻祖窍之内，此为蛰龙之法。后有阳神真火养足，贯入窍中，直待四大崩散，虚空粉碎。是如何闭住炼化色身 ? 是何是蛰龙之法 ? 如何将四大一身崩散 ? 即乞老师乐知。 "

　　了空禅师答曰 :" 丹经万卷，俱藏头露尾，非得口口相传 ; 心心相印，句句可考。细究此理，无不成矣。丹经云 : ‘阅尽丹经万万篇，末后一着无人言。阳关一闭准长生，千佛万祖皆单传。’诀日 : ‘百尺竿头取进步，把个疑团打破时。’尔可摆香案，焚表发愿，后准传一人，不可多传。由古至今，祖祖单传，尔要明自修道，修的是什么 ? 炼的是什么 ? 成道成的是什么 ? 天下万物是什么成的 ? 生人是什么生的 ?"

　　顺一子焚香表后跪而求之，乞师示下。

　　 " 尔修道也，修的是先天祖气，炼的也是祖气，成道成的也是祖气。天下万物也是气生的，人也是父母祖气所生。万物有气则成，元气则坏。大有祖气则生，无祖气则死。尔将祖气修得圆圆陀陀，百尺竿头再进一步，将周身大小窍炼得光明，为有阳关一窍，不可发光明。须得再进一步，炼得通身神火化成先天祖气，成为这个○。聚者能成元身，散者能成空气。恐不得此气，后天色身不能化为气，故有留身之说，皆渭此也。又在自己作德，祖上有德无德。若无德 : 有留身在世，故有尸解之诀，为撤手之法也。用撒手者，诀云 : 日内上腾是天池穴，通脑髓中气胞。

　　 " 吾人说话，出先天真气，故去日出于言不损自伤。尔不知上腭后有个玄膺穴，上通真气胞，下通十二重楼，即是通肺气管，尔将舌逼过吊中，即是巧舌肉帘后， " 是玄膺穴。用舌尖顶住玄膺穴，人不能自主矣，说话不是活人。舌尖闭住，真气不通，故身不能自动，如死人一样。昔年老比丘，用的是此法。修道若不愿意在世界，用此法为老比丘。若有人将舌放开，此老比丘即能复生说话。因肉身能通真气，故而复活。此玄鹰穴两旁有薄肉如帘，有前帘、后帘，中有核，大如否仁，生脂以润喉咙，为口之界。由古至今各位祖师秘而不传，单传至今，尔要细心悟之。 "

　　了然禅师曰：“九年面壁、虚空粉棒之法诀，韬光依灭尽定而寂灭之，寂灭日久，直至三年、九载，空定衡极；灭尽无余之际，神光周足，法相圆满 ; 色空俱泯， " 形神俱妙。其敛也，至精至彻，纳入芥子而无间。其放也，至大至刚，包罗须弥而无外。将见无极种光，化为大红光，恰似赫赫日轮，从太虚玄关窍内一涌而出，崩开分散，灿烂弥满，无边无量。为万道毫光透彻于九天乏生，贯通苛九地之下 ; 若千万果日放大光明，普照三千大千世齐 " 而圣也、贤也、仙也、佛也及森罗万象，莫不齐现于玄关之中， " 然至蛔空囊小而犹未尽其妙也。”

　　余胞兄赵魁一，由民国七年二月过大关，炼至三年后，胎可山，显于平西府铺内 ; 正月出胎，当时可买黄瓜一对，众目所观。由此大家兴起 ; ，修炼性命真功。余当时问白 :" 兄玄功至此，可为仙佛否 ? 往后可有功作？ "

　　余兄师曰 :" 古仙云 : ‘身外有身未可奇，虚空粉碎，方露全真。’所以出胎之后，正要脚踏实地作功，炼得虚空粉碎，方为了当。现在吾不能照耀四大部州，只可再敛神韬光，依灭尽定而寂灭之 ; 即是顿法无为之禅功。不记年月，直至虚空粉碎，与道合真，才见无量之宝光，直充塞于四大，得与贤圣仙佛相会，自无始分离。今日方得会面，彼此交光，合并二体，成为虚无一个圈子。我师犹如摩尼珠，光耀无比。仙佛法身入我之光，我光常大伯佛躯，此九年面壁之功，己返到大觉金仙之位，我等功圆行满，天书下诏，十六位大觉金仙合一，上朝金阴，封以真诰，授以天爵，封为十六合二大觉金仙之位也。”

　　刘名瑞敲跷老师在昌平州西山桃园观棗又名旮旯巷，实在光绪初年，在庙内过大关后曰 : “道成之后，须要积德累功，却来尘世普济，利人利物，开坛演说，广度有缘，著丹经接引后学，辟除左道旁门，诛一切邪教妖言，劝迷人弃伪归正，化贤良觉知魔事。功行以毕，听诏飞升，以登天仙之位。起死拔宅，免堕尘轮之苦，何必烦劳后世再投父母胞胎，而红尘之道苦之尽矣。吾愿大丈夫、大孝子精心细悟性命真理。”

　　“教余广看《慧命经》、《金仙证论》、《天仙证理人《仙佛合宗》等书。余幼年初看此书不明白，后得诀，才明白一半。得了空师天命全诀，才明白全旨，知《伍柳他宗》是万古宝书。无明师者，广看经书，不能明自全旨。余后得全诀 : 知我刘老师无得着撒手之法诀，故在次渠村医人，不能飞升。只可脱壳解尸而去，与七祖一样解尸而升。余胞兄赵魁一以会虚空口诀，至今在三省地面。十二年面壁无一信，可见炼虚空粉碎一着之难矣。

　　千峰老人赵避尘曰 : ‘这炼虚空粉碎，由七真祖师后，炼此者鲜矣。余功未至此，师受口诀在焉。非是不传，亦非怕受天谴，实在不易得之粉碎，故达摩祖有九年雪山之功。古仙云 : ‘饶经八万劫，终是落空亡。’亦不知寿命有限而不能修，亦不知得此法炼不到粉碎，解尸而升。

　　 " 余前著炼精化气，是下手之法，炼气化神是转手之法，炼神还虚是了手之法，又炼虚合道为粉碎，是撤手之法也。是由渐法而入顿法，由有为而入无为，由不空而入真空。无上师云 : ‘炼得金丹似月圆，未免有圆还有缺。’丹经云 : ‘阅尽丹经万万篇，末后一着无人言。阳养卞田准长生，千佛万祖皆单传。’干峰老人日 : ‘百尺竿头取进步，把个疑团打破时。撤手不逼玄膺穴，大罗金仙我灵座。’若无得诀者，速访明师，问撤手之法。

　　 " 炼至神火满穴，自内窍达于外窍，外窍九个。九窍之中，窍窍皆有神。小窍八万四千之中，窍窍皆有灵光。彻内彻外，透底透顶，在在皆有神光。如百干灯光，照耀一室，灯灯互火召光也。散去则无数，收之而为一。炼到此时，超出三干大干世界。又于三千大干之中，复放无量宝光，直充塞于极乐世界。我身犹如摩尼宝珠，诸佛法身入我身体，我身常人诸佛躯。一佛、二佛、千万佛，总是自心无别物。昔年自修善根基，今日依然得渠力。荷泽禅师云 ; 。‘本来面目是真如，舍利光中认得渠。万劫迷头今始悟，方知自性是文珠。’自性清净，便是无垢佛。自性如如，便是自在佛。自性不昧，便是光明佛。自性坚圃，便是不坏佛。位位诸佛，官身俱有。说亦不尽，唯一性尔。

　　 " 性即是心，心职是佛。新佛旧成曾无二体，金身也是这个○，法身也是这个○ ; 本来面目也是这个○，虚空也是这个○，上乎天下乎地全是这个○。天地有坏，这个○不坏。请问这个○，是个什么 ? 是天地、人、身、万物真阴阳之气，炼至纯阳真气，成为这个○，才是真我，才是真性命，才是金仙不坏真体，才是不生不灭之元神，才是一切无有如来佛。”

　　十六步口诀终。

　　玄湘子果仲莲问曰 :" 弟子看丹经道书 ; 每言道在眼前人不知。马丹阳祖师曰 : ‘玄微妙诀无多言，只在眼前人不顾。’又曰：‘道在眼前甚容易，得服之人妙难比。’陈泥丸曰：‘眼前有路不知处，造空伏死徒具宾。’又曰：‘大道分明在眼前。’又曰：‘终曰相随在目前。’张三丰祖师曰：‘今日方知道在眼前。’薛道光祖师曰 : 。思量只是眼睛前，自是时人不见。’刘海蟾祖师曰：‘眼前觑着不识真。’萧紫虚曰：‘金液还丹在眼前，迷者多而悟者少。’上阳子曰：‘此窍分明在目前。’吕祖曰 : ‘目前咫尺长生路，多少愚人不细悟。’吕祖又曰：‘真阴真阳是真道，只在眼前何远讨 ? ’胛世鲜 ?/FONT>: ‘眼前有道’是个什么？ "

　　千峰老人答曰 :" 各位祖师言的是性命双修、三品合一，先天真气，发生后前 ; 又名玄关。修道修的是此气，参禅打坐炼的也是此气，成道也是此气， " 故此气无得可说 ; 强名曰‘道’。是下手采药，性命双修，炼避此气为玄关，又为真，匹，故尔在目前，非是枯坐盲修瞎炼，单炼阴性。是自己一人下手，性命双修，炼出阳性之气光在眼前。 "

　　玄素姑余素霞问曰 :" 丹经每言修道最简最易，无多文字。 "

　　“《六祖坛经》五祖传六祖三更时，片时暗点，无多文字，最简易。

　　“《黄庭经》曰：‘至道不烦诀存真。’又曰：‘治生之道了不烦。’

　　“《参同契》曰：‘事省而不烦。’

　　“钟离祖曰：‘此道分明事不多，奈缘福薄执迷何 ? ’

　　“萧紫虚曰 : ‘从来至道无多事，自是愚人识不全。’

　　“白紫清曰 : ‘只缘简易妙天机，散在丹经不肯泄。’

　　“石杏林曰：‘简易之语，不过半句。证验之效，只在片时。’

　　“张紫阳曰：‘知者唯简唯易，昧者愈烦愈难。’又曰：‘虽愚昧小人，行之立跻圣地。’

　　“薛紫贤曰：‘其道至简，其事非遥，但非丰功伟行，不能遭遇真师。’

　　“请问老师如何简易，是实事 ? 是讲理 ? 气师示知。”

　　千峰老人答曰 :" 此是乾生下手擒白虎之法诀，坤生⒀斩赤龙之诀也。由古至今，祖祖亲传，不作文字。若遇真师，最简最易。若是吸空气，为下手采药， " 揉小肚子、揉两乳、吸空气、为轩赤龙。妄引丹经，猜度之见，误己误人，罪恶不小。 "

　　玄瑞子郑瑞生问曰 :" 弟子看丹经道书，每到真口诀地方，言‘可笑’。

　　“《悟真》曰：‘功夫容易药非遥，说破世人须失笑。’

　　“薛道光曰：‘神仙不肯分明说，说与分明笑杀人。’

　　“吕祖曰 : ‘性命根，生死窍，说着丑，行着妙。人人僧，个个笑。’

　　“《葫芦歌》曰：‘行着妙，说着丑，惹得遇大笑破口。’

　　“上阳子曰：‘偶获一人。两人知之，即来千人、万人之谤。’

　　“石杏林曰：‘此道易生毁谤。’

　　“老子曰 : ‘下士闻道大笑之。’

　　“请问老师 : 又不是闺丹食气、食秽之法，又不是房中来补之法，有何可笑 ? 所笑者何事，惹的世人惊疑 ? 乞师示知。 "

　　千峰老人答曰 :" 所笑者，调外药也。药不调不生，不知调药之功，无药可采。调药者，正在二候正子时，不老不嫩，调的药产神知，可采药也。谓此调法可。’

　　“余胞兄赵魁一曰 : ‘调外药，真可笑。尔不笑，不知道。 '

　　“了然、了空掸师曰 : ‘到二候正子时，可调药采取先天真气。 '

　　“敲跷道师著《道源精微》曰 : ‘调药一着，乃上天之秘宝，弗敢妄泄矣。 '

　　“张懋德，号润亭师叔曰：‘调外药，即勒阳关，所以精气生也。’

　　“柳华阳师爷云：‘勒阳关，调外药，调到药产神知。’

　　“冲虚子师祖云：‘调动其机，精生气动，采取之谓也。 '

　　“曹还阳祖师云：‘药不先调，精无所生也。 '

　　“李虚庵曰：‘忙里愉闲调外药。 '"

　　玄贤姑王淑贤问曰 : “丹经、世人皆言‘性命双修’，而大又爱身家，不借性命，只知独坐孤修。不知离宫⒃入定，坎府⒄求玄之妙理。始则以性而修命，终则以呻而全性。初关炼精化气，为筑基之事 ; 中关炼气化神，是结胎艺事 ; 上关炼神还虚，是了手之事。初关为人仙，中关为神仙，上关本天仙。师传由色界⒅而升无色界⒆，是性命双修之真理。请问老师 : 这奴锋是两人同修 ? 是少肾合一处为双修 ? 乞师示知。”

　　千蜂老人答曰 : “非是两人同修、心肾合一为双修，通不是双修法诀这性命双修，是一人身上神气而矣。神与气交，能生舍利子，是初关之举诀，中养气与气交，能生先天真一之气，能结胎。上关神与神交，能出阳神。此为性命双修真功，非是闭目枯坐瞎修，无所成也。”

　　妙禅姑宋云芳问曰：“师爷前所著十六步大功细而又细，可有简易口诀传出 ? 我以好记。”

　　千峰老人答曰：“初步 : 垂帘冥心守祖窍，手脚和合扣连环。二步 : 气安炉鼎前后转，无孔双吹收元精。三步 :" 开通八脉气血走，手脚麻木气通行。四步 : 下手采药六候转，巽风囊龠沐浴中。正步 : 日月合并渣滓出，文火温养要七成。六步 : 进阳三六由左转，道符二四性光生。七步 :. 翕聚祖气收光法，送归土府神气凝。大步 : 心肾相交真气动，坎离交媾舟团温。九步 : 四个吸呼法轮转，若用口鼻道不真。十步 : 龙虎二穴收精气，舌接任督转法轮、十一步 ; 灵丹入鼎吞入腹，虚室生白百脉停。十二步 : 龙吟虎啸温养丹 ; 片时黄芽白雪生 : 十三步 : 上火采药过大关，五龙棒圣吸撮闭。十四步，提到中宫养圣胎 ; 真空炼形慧光生。十五步，胎足念动朝元法，二光合一中显形，十六步，身外有身不为奇，虚空粉碎归这个圆，此十六步口诀记在心内，用功时而不忘也。”

　　开通八脉怎么走？   手脚麻木怎么行？下手功夫怎采药？   巽风六候怎转轮？

　　四相和合怎返照？   五行攒簇怎用功？卯酉周天懂不懂？   阳火阴符怎转轮？

　　翕聚祖气归何处？   守中抱一怎用功？蛰藏气穴在何处？   必肾相交怎么行？

　　大周吸呼用四个，若用口鼻道不真；三宝若失怎样防？   真气若走怎么封？

　　舍利若成怎知道？   灵丹脱落怎收功？龙吟虎啸在何处？   止火景到怎用功？

　　金光三现怎过关？   牛羊鹿车怎上行？舍利成珠怎牵上？   温养中宫胎怎成？

　　牟尼成胎是什么？   三年乳哺怎补功？道胎圆满怎出胎？   此法不明胎失坑。

　　速访明师求真诀，一失人身再复难。若问此篇何人著？   千峰老人赵避尘。
